Zouban Triple Code System V1

التوتة = 3 شفرات: N = n! + 10^q + m
القانون الذهبي: 10^q + m <= n*n! - 1
قانون الشفط: لو 10^q + m = n*n! فان q=0,m=0,n=n+1
الجملة الذهبية: لا يوجد خانة من قبلها يساويها في المقدار اللازم لرفعها درجة
